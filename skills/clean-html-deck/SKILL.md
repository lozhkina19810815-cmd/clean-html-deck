# Аккуратная презентация: HTML → PDF

Почему HTML, а не PowerPoint: в HTML агент управляет каждым пикселем, видит результат
сам (рендер в PDF и чтение страниц) и правит до показа человеку. Отсюда «аккуратность».

## 1. До вёрстки — смысл (без этого красиво не будет)
1. Одна мысль на слайд. Заголовок = вывод, а не тема («Чат забывает, агент помнит», а не «Память»).
2. Сначала план слайдов списком: № · заголовок-вывод · что на слайде (цифра / схема / 3 карточки / фото).
3. Текст на слайде — максимум 3–4 блока, в каждом до 2 строк. Остальное — в речь докладчика.

## 2. Каркас (один на всю деку)
- Каждый слайд — `<section class="slide">` 1920×1080, `@page{size:1920px 1080px;margin:0}`,
  `@media print{.slide{break-after:page}}`.
- Единые поля: контент в `.pad{position:absolute;inset:96px 110px 150px}`, подвал на 56px от низа
  (лого · слоган · номер страницы) с тонкой линией сверху.
- Цвета — только через переменные в `:root`: 1 акцентный, 1 вспомогательный, 1 светлая
  подложка для карточек, чёрный текст, серый для второстепенного, линия #ECECEC. Больше цветов не вводить.
- Два шрифта максимум: акцидентный для заголовков и цифр (у нас Unbounded 700–800),
  текстовый для всего остального (у нас Golos Text). Подключать с Google Fonts, СТАТИЧНЫЕ начертания
  (переменный шрифт в Chrome-PDF может превратиться в кракозябры).
- Шкала размеров фиксированная: обложка 150px, заголовок слайда 62px, подзаголовок-«кикер» 24px
  капсом с разрядкой акцентным цветом, текст карточек 24–30px, крупная цифра 54–200px. Не меньше 22px.

## 3. Приёмы, которые дают «дизайнерский» вид
- Кикер над заголовком (раздел капсом) + заголовок-вывод.
- Карточки на светлой подложке, скругление 18–22px, внутренний отступ 26–40px, гэп 18–26px.
- Ступени/прогрессия: 3–4 колонки разной высоты или от светлой к акцентной заливке.
- Крупная цифра акцентным цветом + подпись мелко рядом.
- Фраза-вывод (punch) по центру внизу слайда акцентным цветом.
- Финальный слайд — заливка акцентом, белый текст, вопрос/контакт.
- Фото: `object-fit:cover`, не резать лица и фасады, одна рамка на слайд.
- Пустое место — это нормально. Не заполнять слайд до краёв.

## 4. Рендер
```bash
python3 -m http.server 8765 --directory <папка_с_deck.html>   # фоном
"/Applications/Google Chrome.app/Contents/MacOS/Google Chrome" --headless --disable-gpu \
  --no-pdf-header-footer --print-to-pdf="<имя>_v1.pdf" "http://localhost:8765/deck.html"
```
Каждая правка — новая версия файла (`_v2`, `_v3`), старые в подпапку «версии».

## 5. Самопроверка ДО показа (обязательно, это и есть «аккуратно»)
1. Открыть PDF и посмотреть КАЖДУЮ страницу целиком (агент читает PDF постранично).
2. Ничего не вылезает за слайд — прогнать в браузере:
```js
[...document.querySelectorAll('.slide')].flatMap((s,i)=>{const b=s.getBoundingClientRect();
 return [...s.querySelectorAll('*')].filter(e=>{const r=e.getBoundingClientRect();
 return r.width&&(r.right>b.right+1||r.bottom>b.bottom+1||r.left<b.left-1)}).map(e=>`слайд ${i+1}: ${e.className||e.tagName}`)})
```
   и `e.scrollHeight>e.clientHeight` для блоков с текстом — текст не обрезан внутри карточки.
3. Блоки не налезают друг на друга; подвал не перекрыт контентом.
4. Нет висячих предлогов и союзов в конце строки: после коротких слов (в, к, с, и, а, не, на, по, за, от, до)
   ставить `&nbsp;`.
5. Орфография всех текстов, названия и цифры — из источника, не по памяти.
6. Один стиль на всех слайдах: те же поля, размеры, цвета, подвал.
Нашёл брак — исправить и проверить заново. Человеку показывать только чистую версию.
